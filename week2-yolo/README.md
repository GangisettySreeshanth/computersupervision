# Week 2 - YOLO Object Detection

## Task
Performed object detection using Ultralytics YOLOv8.

## Steps
1. Created virtual environment using venv
2. Installed ultralytics
3. Ran YOLO model on image

## Command Used
yolo predict model=yolov8n.pt source="https://ultralytics.com/images/bus.jpg"

## Output
Detected objects:
- Person
- Bus
- Stop sign
