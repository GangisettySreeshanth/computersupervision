# Week 1 - Task 1

## Objective

To extract images from a video using FFmpeg.

## Tools Used

* yt-dlp (for downloading video)
* FFmpeg (for extracting frames)

## Procedure

1. Downloaded a short YouTube video using yt-dlp.
2. Used FFmpeg to extract frames from the video.
3. Saved extracted frames as .jpg images.

## Command Used

ffmpeg -i input_video.mp4 frames/frame_%04d.jpg

## Output

* Extracted multiple frames from video
* Sample images attached
