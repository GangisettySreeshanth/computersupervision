# Week 1 - Video to Frame Extraction

## 📌 Objective

To convert a video into image frames for further processing.

## 🛠️ Tools Used

* Python
* OpenCV
* FFmpeg

## ⚙️ Methodology

1. Loaded video using OpenCV
2. Read frames sequentially
3. Saved each frame as an image
4. Stored images in a folder

## 📊 Output

* Extracted multiple frames from input video
* Frames stored as .jpg images
