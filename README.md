# Summer Internship - Computer Vision and Multimedia Processing

This repository contains weekly tasks completed during the summer internship program focused on multimedia processing, computer vision, and YOLO-based object detection.

---

# Week 1 - Video and Audio Processing

* Downloaded YouTube videos using yt-dlp.
* Extracted image frames using FFmpeg.
* Reconstructed videos from image sequences.
* Added background audio/music to generated videos.

# Week 2 - Image Processing Fundamentals

* Performed basic image manipulation and preprocessing tasks.
* Explored multimedia utilities and file handling.

# Week 3 - Dataset Preparation

* Organized image datasets for machine learning workflows.
* Worked on folder structuring and preprocessing automation.

# Week 4 - Label Studio and YOLO Dataset Creation

* Installed and configured Label Studio.
* Annotated cricket player images using bounding boxes.
* Exported annotations in YOLO format.
* Created train/validation datasets and YAML configuration.

# Week 5 - YOLO Training and Object Detection

* Resized images using FFmpeg while preserving aspect ratio.
* Trained YOLOv8 model on custom dataset.
* Performed object detection on test images.
* Generated prediction videos with bounding boxes and audio.
