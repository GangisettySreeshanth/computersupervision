# WT1 - Dataset Labeling using Label Studio

## Objective

Annotate objects for YOLO training using Label Studio.

## Tools Used

* Label Studio
* YOLO Format Export

## Steps Performed

1. Installed Label Studio in virtual environment
2. Opened interface in browser
3. Created object labels
4. Annotated images with bounding boxes
5. Exported dataset in YOLO format
6. Created train and validation splits
7. Generated dataset.yaml file

## Output

* Labeled images
* YOLO label files
* dataset.yaml

## Learning Outcome

* Understood object annotation workflow
* Learned YOLO dataset structure
