# WT3 - YOLOv8 Training and Loss Analysis

## Objective

Train YOLOv8 model and analyze training/validation losses.

## Model Used

* YOLOv8n

## Parameters

* Epochs: 50
* Image Size: 384

## Procedure

1. Loaded pretrained YOLOv8 model
2. Trained model on custom dataset
3. Observed training and validation losses
4. Saved trained weights

## Observation

* Initially both losses decreased
* Validation loss increased after certain epochs, indicating overfitting

## Output

* Trained weights: best.pt

## Learning Outcome

* Understood transfer learning
* Learned overfitting behavior
* Learned training analytics interpretation
