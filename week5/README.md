# Week 5 - Computer Vision using YOLO

## WT1 - Labeling

Annotated cricket player images using Label Studio and exported dataset in YOLO format.

## WT2 - Image Resizing

Resized images using FFmpeg while preserving aspect ratio for efficient training.

## WT3 - YOLO Training

Trained YOLOv8 model on custom dataset and observed training/validation losses.

## WT4 - Object Detection

Performed prediction on test images and generated outputs with bounding boxes.

## WT5 - Final Video Generation

Converted prediction outputs into video and added background music using FFmpeg.

## Learning Outcome

Learned the complete computer vision workflow:
annotation → preprocessing → training → prediction → video generation.
