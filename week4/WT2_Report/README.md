# WT2 - YOLOv8 Implementation

## 📌 Objective

Detect cricket players using YOLOv8.

## ⚙️ Steps Performed

1. Collected video and extracted frames
2. Labeled images using Label Studio
3. Exported dataset in YOLO format
4. Cleaned labels and filenames
5. Split dataset into train and validation
6. Trained YOLOv8 model
7. Performed predictions

## 📊 Result

* Model trained successfully
* Predictions generated
* Limited accuracy due to small dataset

## 📁 Files

* dataset/
* dataset.yaml
* train.py
* predict.py

## ⚠️ Note

Detection results are weak due to limited labeled data.
